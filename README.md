# Bat-Ball-Stump Game

A browser game played against the computer, inspired by rock-paper-scissors with a cricket twist. Pick **Bat**, **Ball** or **Stump** and see who wins.

## Rules

- Bat beats Ball
- Ball beats Stump
- Stump beats Bat
- Same choice on both sides is a tie

## Tech stack

HTML, CSS and vanilla JavaScript.
